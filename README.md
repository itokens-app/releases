# itokens releases

Signed and notarized downloads of [itokens](https://itokens.app) for Apple Silicon Macs (M1 or later, macOS 14 or
later), and the notes for every release: see [Releases](../../releases).

- **Homebrew:** `brew install --cask itokens-app/tap/itokens`
- **Disk image:** download `itokens_v<version>.dmg` from the latest release, open it and drag itokens to Applications.
- Every release lists SHA-256 checksums in `SHA256SUMS`.

itokens updates itself (it asks first) from here. Bugs go to [itokens-app/issues](https://github.com/itokens-app/issues),
or use **Report a bug** in the app.
